# LocalPros

**LocalPros** is a native Android mobile application that connects local service professionals with clients who need their services. The platform facilitates the hiring of home and trade services through geolocation.

## 🏗️ Main Technologies

- **Native Android** (Kotlin)
- **Jetpack Compose** - Modern declarative UI
- **Firebase** - Complete backend (Auth, Firestore, Analytics, Crashlytics)
- **Google Maps API** - Geolocation services
- **Hilt/Dagger** - Dependency injection
- **Material Design 3** - UI components

## 🎯 Key Features

### For Clients (Individuals)
- Job/service offer posting
- Geolocated professional search
- Budget and material quality management
- Evaluation and review system

### For Professionals
- Professional profile with performance indicators
- Temporal and geographic availability management
- Job offer applications
- Reputation and rating system

## 🏢 Service Categories

The application covers over 20 professional categories:

- **Construction**: Mason, Electrician, Plumber, Carpenter, Painter
- **Maintenance**: Gardener, Mechanic, Welder, Locksmith
- **Technicians**: HVAC, Refrigeration, Appliances, IT
- **Specialized**: Renewable Energy, Security, Telecommunications
- **Others**: Cleaning, Integral Renovations, and more

## 🏛️ Architecture

- **MVVM Pattern** with ViewModels
- **Clean Architecture** with separated layers
- **Repository Pattern** for data management
- **Dependency Injection** with Hilt

## 🚀 Project Setup

### Prerequisites
- Android Studio Hedgehog | 2023.1.1+
- JDK 17+
- Android SDK (API 23-34)
- Google Cloud Platform account (for Maps API)
- Firebase project

### Installation
1. Clone the repository
2. Set up your Firebase `google-services.json` file
3. Add your Google Maps API key in `build.gradle.kts`
4. Sync project with Gradle
