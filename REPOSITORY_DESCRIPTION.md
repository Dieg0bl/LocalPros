# Descripción Sugerida para la Sección "About" del Repositorio

## Descripción Corta (para GitHub About)

**Aplicación móvil Android (Kotlin + Jetpack Compose) que conecta profesionales de servicios locales con clientes. Marketplace de servicios domésticos con geolocalización, Firebase y Google Maps.**

## Descripción Extendida (Alternativa)

**LocalPros es una aplicación nativa de Android desarrollada en Kotlin que facilita la conexión entre profesionales de servicios locales y clientes. Utiliza Jetpack Compose, Firebase, Google Maps y Material Design 3 para crear un marketplace geolocalizado de servicios domésticos y oficios.**

## Instrucciones para el Propietario del Repositorio

Para actualizar la descripción del repositorio en GitHub:

1. Ve a la página principal del repositorio en GitHub
2. Haz clic en el ícono de engranaje (⚙️) en la sección "About" 
3. Copia y pega una de las descripciones sugeridas arriba
4. Añade las etiquetas (topics) sugeridas
5. Guarda los cambios

La descripción elegida debe ser comprensible tanto para desarrolladores (que entenderán las tecnologías) como para reclutadores (que entenderán el propósito del negocio).
